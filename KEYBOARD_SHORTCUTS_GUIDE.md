# 🎹 Guía Rápida de Atajos de Teclado

## Acceso a los Atajos

Presiona **`Shift + ?`** en cualquier momento para abrir el panel interactivo de atajos de teclado.

## Atajos Disponibles

### 🎵 Gestión de Canciones

| Atajo | Acción |
|-------|--------|
| `Ctrl + N` | Crear una nueva canción |
| `Ctrl + S` | Guardar cambios |
| `Ctrl + Shift + P` | Publicar la canción actual |

### 🌙 Apariencia

| Atajo | Acción |
|-------|--------|
| `Ctrl + T` | Cambiar entre tema claro y oscuro |

### 🔄 Sincronización

| Atajo | Acción |
|-------|--------|
| `Ctrl + G` | Abrir el modal de sincronización con Git |

### ✏️ Edición

| Atajo | Acción |
|-------|--------|
| `Ctrl + Z` | Deshacer la última acción |
| `Ctrl + Shift + Z` | Rehacer la acción deshecha |

### 🎯 Navegación

| Atajo | Acción |
|-------|--------|
| `Tab` | Navegar al siguiente elemento enfocable |
| `Shift + Tab` | Navegar al elemento enfocable anterior |
| `Esc` | Cerrar cualquier diálogo o modal abierto |

### 📚 Ayuda

| Atajo | Acción |
|-------|--------|
| `Shift + ?` | Mostrar este panel de atajos de teclado |

## Tips de Uso

### Para Usuarios de Teclado

1. **Navegación por Teclado**: Usa `Tab` para navegar entre elementos
2. **Activar Elementos**: Presiona `Enter` o `Espacio` para activar botones y enlaces
3. **Cerrar Diálogos**: Presiona `Esc` para cerrar cualquier modal o diálogo abierto
4. **Enfoque Visible**: Verás un contorno de color alrededor del elemento que tiene enfoque

### Compatibilidad con el Sistema

La aplicación respeta las preferencias de accesibilidad de tu sistema operativo:

- **Reducción de Movimiento**: Si tienes habilitada la reducción de movimiento en tu SO, las animaciones se desactivarán automáticamente
- **Contraste Alto**: En sistemas con modo de alto contraste, los bordes y controles tendrán mayor visibilidad

### Para Usuarios de Lectores de Pantalla

Todos los atajos de teclado están optimizados para funcionar correctamente con lectores de pantalla como:
- **NVDA** (Windows)
- **JAWS** (Windows)
- **VoiceOver** (macOS/iOS)

Cada control tiene etiquetas ARIA apropiadas para que el lector de pantalla anuncie correctamente su propósito.

## Ejemplos de Flujo de Trabajo

### Crear y Publicar una Canción Rápidamente

1. Presiona `Ctrl + N` → Se abre el editor de canciones
2. Completa los detalles de la canción
3. Presiona `Ctrl + S` → Guardar cambios
4. Presiona `Ctrl + Shift + P` → Publicar la canción
5. Presiona `Esc` → Cerrar el modal

### Sincronizar Cambios con Git

1. Presiona `Ctrl + G` → Se abre el modal de Git Sync
2. Revisa los cambios sin sincronizar
3. Haz clic en "Sincronizar" o presiona el botón correspondiente
4. Presiona `Esc` → Cerrar el modal cuando esté listo

### Cambiar Tema Oscuro/Claro

1. Presiona `Ctrl + T` en cualquier momento
2. El tema cambia inmediatamente
3. Tu preferencia se guarda automáticamente
