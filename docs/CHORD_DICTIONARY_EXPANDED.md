## 🎯 Distribución por Dificultad

Los acordes están clasificados en 3 niveles de dificultad:

### 🟢 Fácil (Easy)
- Posiciones abiertas (trastes 0-3)
- Generalmente sin cejilla
- Ejemplo: Am, E, D

### 🟡 Medio (Medium)
- Posiciones con cejilla parcial o completa
- Trastes del 3 al 8
- Ejemplo: F, Bm, G7

### 🔴 Difícil (Hard)
- Posiciones con cejilla completa en trastes altos
- Requiere mayor control y fuerza
- Ejemplo: B, B7, B#dim

## 📍 Generación de Posiciones

Cada acorde está generado algorítmicamente basándose en:

1. **Fórmula de Intervalo**: Define qué notas constituyen el acorde
2. **Afinación Estándar**: E-A-D-G-B-E (afinación de guitarra estándar)
3. **Búsqueda Óptima**: Se buscan hasta 4 posiciones diferentes en el diapasón
4. **Validación**: Cada posición se valida para asegurar que contiene al menos:
   - La nota raíz
   - Mínimo 2 notas de la fórmula del acorde

### Ejemplo: Acorde de Do Mayor (C)
```
Fórmula: 1 (C) - 3 (E) - 5 (G)

Posición 1 (Abierta): X 3 2 0 1 0
Posición 2 (Traste 3): 3 3 2 0 1 0
Posición 3 (Traste 8): 8 10 10 9 8 8
Posición 4 (Traste 15): 15 17 17 16 15 15
```

## 🔤 Interpretación de Frets

El array `frets` representa las 6 cuerdas de guitarra (de más aguda a más grave):

| Índice | Cuerda | Nota Abierta |
|--------|--------|--------------|
| 0 | 1ª (Mi agudo) | E |
| 1 | 2ª (Si) | B |
| 2 | 3ª (Sol) | G |
| 3 | 4ª (Re) | D |
| 4 | 5ª (La) | A |
| 5 | 6ª (Mi grave) | E |

**Valores en el array:**
- `-1`: Cuerda no pulsada (muda)
- `0`: Cuerda abierta
- `1-22`: Número del traste a pulsar

```tsx

// Obtener una posición específica
const position = chordDictionaryService.getChordPosition('C', 0);

// Verificar si hay múltiples posiciones
const hasMultiple = chordDictionaryService.hasMultiplePositions('Am');
```

## 🎓 Casos de Uso Comunes

### 1. Principiantes
Los acordes marcados como **"easy"** son ideales:
- Am, E, D (posiciones abiertas)
- Estos usan principalmente los primeros 3 trastes

### 2. Nivel Intermedio
Una vez dominadas las posiciones abiertas:
- F, Bm (con cejilla parcial)
- Acordes de séptima básicos (C7, G7)

### 3. Músicos Avanzados
Explorar variaciones complejas:
- Acordes extendidos (C9, Cmaj9)
- Acordes disminuidos y aumentados
- Diferentes inversiones y voicings

### 4. Composición y Improvisación
Acceder a todas las posiciones disponibles para:
- Crear diferentes texturas sonoras
- Encontrar transiciones suaves entre acordes
- Explorar nuevas inversiones
