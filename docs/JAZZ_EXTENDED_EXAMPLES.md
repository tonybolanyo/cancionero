## Progresiones Clásicas de Jazz

### 1. ii-V-I Básico en Do Mayor

```
Cmaj7       | Dm7b5    G7#11   | Cmaj7
I (tónica)  | ii-V (tensión)   | I (resolución)
```

**Instrucciones:**
1. Cmaj7: Comienza la progresión
2. Dm7b5: Tensión máxima (semidisminuido)
3. G7#11: Mantén la tensión con la 11ª aumentada
4. Cmaj7: Resuelve satisfactoriamente

---

### 2. Turnaround Moderno

```
Cmaj7     | Cmaj13    | Cmaj7    | Cmaj13
```

**Efecto:** Lujoso y fluido, muy usado en ballads de jazz

---

### 3. Progresión de Soul/Neo-soul

```
Fmaj13    | Fmaj13    | Cmaj13   | Cmaj13
IV-maj13  |           | I-maj13  |
```

**Efecto:** Moderno, sofisticado, perfecto para R&B contemporáneo

---

### 4. Dominante Alterada

```
Cmaj7     | C7alt     | Fmaj7
I         | V alterada| IV
```

**Nota:** C7alt mantiene máxima tensión antes de resolver a Fmaj7

---

### 5. ii-V-I Extendido (Jazz Avanzado)

```
Cmaj7       | Dm7b5    | G7#11    | Cmaj13
Fundamental | ii-V     | Tensión  | Resolución lujosa
```

## Canción Ejemplo: "Night and Day"

**Progresión armónica con extensiones:**

```
Cmaj7     | Dm7b5 G7alt  | Cmaj7     | A7alt
Dm7b5     | G13          | Cmaj13    | Cmaj13
```

**Notas de interpretación:**
- Cmaj7: Inicio tranquilo
- G7alt: Crea expectativa
- Cmaj13: Resolución sofisticada
- G13: Dominante extendida

## Comparativa: Acordes Básicos vs Extendidos

### Versión Simple

```
Cmaj7  | Dm7b5 G7  | Cmaj7
```

**Sonoridad:** Clásica, clara, tradicional

---

### Versión Extendida

```
Cmaj7  | Dm7b5 G7#11 | Cmaj13
```

**Sonoridad:** Moderna, lujosa, sofisticada

**Diferencia:** 
- G7 vs G7#11: La 11ª aumentada añade brillo
- Cmaj7 vs Cmaj13: La 13ª añade amplitud y calidez

## Tips de Práctica

### Para Principiantes

1. **Comienza con 6ª:** C6, Dm6 → Sonido hermoso con digitación simple
2. **Luego m7b5:** Dm7b5 → Es la base del jazz
3. **Después 13ª:** Cmaj13 → Lujoso pero accesible

### Para Intermedios

1. **Domina todas las variantes de m7b5** en diferentes trastes
2. **Practica transiciones:** G7#11 → Cmaj7
3. **Experimenta con 7alt:** Siéntelo, no memorices la teoría

### Para Avanzados

1. **Voicing alternativo:** Encuentra múltiples posiciones para cada acorde
2. **Comping jazz:** Sustituye acordes tradicionales con extensiones
3. **Arreglos:** Usa 13ª para finales de frases

## Notas Especiales

### Voicing en la Guitarra
- Algunos acordes tienen múltiples posiciones
- Elige la que mejor se adapte a tu contexto
- Considera la progresión siguiente para voice leading suave

### Omisión de Notas
En acordes muy complejos, es común omitir:
- La fundamental (es implícita si está en otra cuerda)
- La quinta (menos importante que tercera y séptima)
- La novena (si no es el enfoque)

### Contexto Armónico
Un mismo acorde puede sonar diferente según:
- Lo que venga antes
- Lo que venga después
- El tempo y el groove
